# Global Freedom Cases

Global Load Cases
With the function St7SetLoadCaseType the type of inertia load may be set:

kNoInertia

No inertia load

kGravity

Load case type is set to gravity

kAccelerations

All velocities and accelerations are considered

Global load case parameters may be modified using the Strand7 API. The integer values
and types (as defined in the include and header files) are shown below.

- `ipRefTemp`

Reference temperature

- `ipGlobOrigX`

Global angular X origin

- `ipGlobOrigY`

Global angular Y origin

- `ipGlobOrigZ`

Global angular Z origin

- `ipGlobAccX`

Global X acceleration

- `ipGlobAccY`

Global Y acceleration

- `ipGlobAccZ`

Global Z acceleration

- `ipGlobAngVelX`

Global angular X velocity

- `ipGlobAngVelY`

Global angular Y velocity

- `ipGlobAngVelZ`

Global angular Z velocity

- `ipGlobAngAccX`

Global angular X acceleration

- `ipGlobAngAccY`

Global angular Y acceleration

- `ipGlobAngAccZ`

Global angular Z acceleration
