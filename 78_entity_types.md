# Entity Types

Global Freedom Cases

Global Freedom Cases
With the function St7SetFreedomCaseType the following freedom types may be set:

kNormalFreedom

normal freedom case

kFreeBodyInertiaRelief

free body inertia relief

kSingleSymmetryInertiaXY

single symmetry inertia relief about the XY-plane

kSingleSymmetryInertiaYZ

single symmetry inertia relief about the YZ-plane

kSingleSymmetryInertiaZX

single symmetry inertia relief about the ZX-plane

kDoubleSymmetryInertiaX

double symmetry inertia relief free along X-axis

kDoubleSymmetryInertiaY

double symmetry inertia relief free along Y-axis

kDoubleSymmetryInertiaZ

double symmetry inertia relief free along Z-axis
